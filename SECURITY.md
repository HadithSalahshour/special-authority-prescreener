# Security policy

## Supported version

Only the latest commit on the default branch is supported during prototype development.

## Reporting

Do not open a public issue containing credentials, patient information, or a working
exploit. Contact the repository owner privately through their GitHub profile.

## Scope notes

The included launcher is loopback-only and the repository uses synthetic data. If you
change the bind address, add authentication, authorization, TLS, rate limiting, audit
logging, and a formal privacy review before exposing the service to another device.
